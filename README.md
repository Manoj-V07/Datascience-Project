# Disaster Relief Resource Allocation Analytics

**“Right Resource. Right Place. Right Time.”**

## Project Overview
This project aims to analyze disaster-affected regions, predict relief-resource demand, prioritize affected zones, and eventually optimize the allocation of limited resources.

## Structure
- `data/`: Raw and processed datasets.
- `notebooks/`: Exploratory Data Analysis.
- `src/`: Source code for preprocessing and validation.
- `models/`: Trained ML models.
- `reports/`: Phase analysis reports.
